# MyPersonalPortifolio

## 🚀 Key Repository Features

This repository acts as my core personal branding platform, hosting customized UI configurations, modern web layouts, and interactive developer showcase assets:

* **Sleek Dark Theme:** Built with custom clean dark variables carefully balanced with white typographical anchors and colorful accents.
* **Side-by-Side Left Sidebar Layout:** Desktop view split columns balancing fixed personal meta summaries with scrollable project viewports.
* **Smooth 3D Project Animations:** Integrated CSS 3D perspective grids (`rotateX` / `rotateY`) implementing cinematic un-flip entrance reveals.
* **Interactive Contact Hub Grid:** Replaced traditional boring inputs with modern Quick-Connect social card arrays that interact with hover micro-lifts.

## 🛠️ Built With (Tech Stack)

* **HTML5 / CSS3:** Modern layout rendering incorporating semantic components, grid, flexbox layout tools, and advanced `@keyframes` 3D animation systems.
* **Bootstrap 5:** Fluid column grid systems ensuring responsive breaks across desktops, tablets, and mobile screens.
* **JavaScript (ES6+):** Vanilla UI controller script layers driving layout state adjustments cleanly with optimized timing parameters.

## 📥 Local Installation & Setup

To download, inspect, or modify this portfolio workspace layout locally on your computer, execute these quick steps:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/yabets123d-ux/MyPersonalPortifolio.git
   ```

2. **Navigate into the project directory:**
   ```bash
   cd MyPersonalPortifolio
   ```

3. **Launch the code workspace:**
   * Open `index.html` inside your favorite internet browser (e.g., Chrome, Brave, Safari).
   * Or run it through a local server container system such as the VS Code *Live Server Extension*
